Quiero diseñar una aplicación web responsive para la gestión y reserva de stands en eventos.

IMPORTANTE:
Voy a proporcionar imágenes del plano del evento. El sistema debe usar esas imágenes como base visual del mapa. Sin embargo, debe existir una opción para configurar manualmente los stands en caso de que las posiciones no coincidan perfectamente.

---

## OBJETIVO

Permitir que usuarios se registren, inicien sesión y reserven stands desde un mapa interactivo basado en un plano real.

Debe existir un rol de super administrador para gestionar todo el sistema.

---

## ROLES

1. Super administrador
2. Usuario expositor

---

## PANTALLAS PRINCIPALES

1. Inicio

* Login
* Registro
* Acceso a eventos

2. Registro

* Nombre
* Apellido
* Email
* Teléfono
* Contraseña

3. Login

* Email
* Contraseña

4. Listado de eventos

* Mostrar eventos como tarjetas
* Nombre
* Fecha
* Estado

5. Mapa de stands (principal)

* Usar imagen del plano como fondo
* Los stands deben ser elementos clickeables posicionados sobre el plano

Estados visuales:

* Verde → disponible
* Amarillo → pendiente
* Rojo → reservado
* Gris → bloqueado

Interacción:

* Click en stand → abrir modal con:

  * número
  * precio
  * estado
  * botón reservar (solo si está disponible)

---

## MODO EDICIÓN DE STANDS (MUY IMPORTANTE)

El super administrador debe tener un modo de edición manual del mapa.

Funciones:

* Agregar stand manualmente
* Editar stand existente
* Eliminar stand
* Definir:

  * número del stand (ej: 5, 23, G1)
  * precio
  * posición (arrastrando sobre el mapa o ingresando coordenadas)
  * sector (salón / galería)

Debe existir un botón:
"Modo edición"

En este modo:

* Se pueden mover stands sobre el plano (drag & drop)
* Se pueden crear nuevos stands si no fueron detectados correctamente
* Se pueden corregir posiciones

Esto es clave para ajustar el mapa si la imagen no coincide perfectamente.
