-----------------------------------
CATEGORÍAS DE STANDS
-----------------------------------

El sistema debe permitir clasificar los stands por categorías.

Ejemplos:
- Comerciales
- Gastronómicos
- Ilustradores

IMPORTANTE:
Las categorías NO deben ser fijas. El super administrador debe poder gestionarlas.

Funciones del super admin:
- crear categorías
- editar nombre de categoría
- eliminar categorías

-----------------------------------
FORMULARIO DE RESERVA
-----------------------------------

Agregar campo obligatorio:

- Categoría del stand

Tipo:
- selector (dropdown)

Reglas:
- el usuario debe elegir una categoría
- no permitir continuar sin seleccionar

-----------------------------------
MODO EDICIÓN DE STANDS
-----------------------------------

En el modo edición manual:

Cada stand debe permitir:
- asignar categoría
- modificar categoría
- ver categoría actual

-----------------------------------
PANEL ADMIN
-----------------------------------

El super admin debe poder:

- ver categoría en cada reserva
- filtrar reservas por categoría
- visualizar distribución por categoría
- cambiar categoría manualmente

-----------------------------------
MAPA
-----------------------------------

El mapa puede usar colores o indicadores visuales para diferenciar categorías.

Ejemplo:
- Comerciales → azul
- Gastronómicos → naranja
- Ilustradores → violeta

-----------------------------------
EXPORTACIÓN
-----------------------------------

El Excel debe incluir:
- categoría del stand
